# vla_arm

## Create a Python virtual environment (venv)

From the repo root (C:\Users\cyani\Desktop\vla_arm):

```powershell
python -m venv .venv
```

## Python virtual environment (venv)

### Activate (Windows PowerShell)

```powershell
& .\.venv\Scripts\Activate.ps1
```

### Activate (Windows cmd)

```bat
.venv\Scripts\activate.bat
```

### Deactivate

```powershell
Deactivate
```

## Run Python

```powershell
python your_script.py
```

> Replace `your_script.py` with the file you want to run (e.g., `ded.py`).
